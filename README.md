# Lua Family Bucket

[English](README.md) | [简体中文](README.zh-CN.md)

> A curated collection of essential Lua tools and libraries (binding, debugging, profiling, optimization, and monitoring).

---

## Selection Guide

Pick a tool by need. Short descriptions of each project are in the list below.

| Scenario | Tool | Purpose / tip |
| --- | --- | --- |
| Bind Lua and C++ | [bLua](https://github.com/esrrhs/bLua) | Lua and C++ binding library |
| Measure code coverage | [cLua](https://github.com/esrrhs/cLua) | Lua code coverage tool |
| Debug Lua programs | [dLua](https://github.com/esrrhs/dLua) | Lua debugger |
| Compute diffs and patches | [fLua](https://github.com/esrrhs/fLua) | Lua diff and patch tool |
| Optimize or analyze memory | [mLua](https://github.com/esrrhs/mLua) | Lua memory optimization and analysis tool |
| Optimize bytecode | [oLua](https://github.com/esrrhs/oLua) | Lua optimizer |
| Profile program performance | [pLua](https://github.com/esrrhs/pLua) | Lua performance profiler |
| Analyze VM internals and instructions | [vLua](https://github.com/esrrhs/vLua) | Lua VM profiler and analysis tool |
| Watch runtime state and metrics | [wLua](https://github.com/esrrhs/wLua) | Lua state and metrics watcher/monitor |

**How to tell pLua / vLua and mLua / wLua apart**

- **pLua** vs **vLua**: pLua is a performance profiler for Lua programs. vLua profiles and analyzes Lua VM internals and instructions, attributing CPU time in a chosen Lua VM C function back to Lua source lines.
- **mLua** vs **wLua**: mLua is for memory optimization and analysis. wLua watches and monitors a running Lua state's metrics.
